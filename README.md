# Lab 2 – Identifying ML Problems & Methodology

## Dataset: Medical Insurance Cost

**Source:** Kaggle – Medical Cost Personal Datasets  
**File:** `insurance.csv`  
**Shape:** 1338 rows × 7 columns  

### Features

| Column | Type | Description |
|---|---|---|
| age | int | Age of the primary beneficiary (18–64) |
| sex | string | Biological sex of the beneficiary: male / female |
| bmi | float | Body Mass Index (kg/m²) — ideal range: 18.5–24.9 |
| children | int | Number of children covered by the insurance plan (0–5) |
| smoker | string | Whether the beneficiary smokes: yes / no |
| region | string | US residential area: northeast / northwest / southeast / southwest |
| charges | float | **Target (regression)** — individual medical insurance cost billed (USD) |

---

## Machine Learning Problem

**Primary Task:** Predict individual **medical insurance charges** based on personal attributes.  
**Problem Type:** Regression (continuous target → `charges`)  

**Secondary Task (Labs 5, 7, 8):** Predict whether a beneficiary is a **smoker** (yes/no).  
**Problem Type:** Binary Classification (target → `smoker`)

**Why this dataset?**
- Fully tabular — no images, audio, or unstructured text.
- Mix of numeric (`age`, `bmi`, `children`, `charges`) and categorical (`sex`, `smoker`, `region`) features.
- `charges` is a natural regression target; `smoker` is a natural binary classification target.
- Real-world relevance: insurance pricing, healthcare cost modelling.
- Clean structure with identifiable data quality issues (outliers, skew) suitable for preprocessing.

---

## Methodology Overview

1. **Data Collection** → Load `insurance.csv` with Pandas
2. **EDA** → Visualise distributions, correlations, smoker vs non-smoker charge distributions
3. **Preprocessing** → Handle outliers (IQR), normalise numeric features, encode categoricals
4. **Feature Engineering** → Create BMI categories, age groups, interaction features
5. **Model Training** → Linear Regression (charges) · Logistic Regression (smoker) · KNN (smoker)
6. **Evaluation** → MAE/MSE/RMSE for regression · Accuracy/F1/AUC for classification
7. **Iteration** → Tune hyperparameters, apply PCA for dimensionality reduction
